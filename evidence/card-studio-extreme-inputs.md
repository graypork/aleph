# Card Studio 극단 입력 12건 검사 기록

검사 기준: 편집 상태가 유지되고, 미리보기와 저장 파일이 같은 렌더 규칙을 사용하며, 잘못된 입력은 기존 작업을 예고 없이 지우지 않아야 한다.

| # | 입력 | 예상 | 결과 | 비고 |
|---:|---|---|---|---|
| 1 | 긴 한글 문장 | 사용 폭 안에서 자동 줄바꿈 | PASS | 공백 단위 줄바꿈 후 필요 시 문자 단위 분할 |
| 2 | 긴 영문 문장 | 사용 폭 안에서 자동 줄바꿈 | PASS | 단어 단위 줄바꿈 |
| 3 | 한글·영문 혼합 | 혼합 문자가 같은 텍스트 블록에 유지 | PASS | 시스템 sans-serif fallback 사용 |
| 4 | 명시적 줄바꿈 `첫 줄\n둘째 줄` | 입력한 줄바꿈이 그대로 분리 | PASS | `\n` 우선 처리 |
| 5 | 이모지 `🚀✨ 오늘도 출발` | 이모지 포함 문구가 사라지지 않음 | PASS | Unicode 문자 단위 분할 |
| 6 | 빈 문구 | 오류 없이 텍스트를 그리지 않음 | PASS | 빈 문자열은 유효 입력 |
| 7 | 특수문자 `#?! @ [] () %` | 특수문자가 그대로 표시 | PASS | HTML 삽입 없이 Canvas text 사용 |
| 8 | 긴 무공백 토큰 `ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789...` | 최대 폭을 넘지 않게 문자 단위 분할 | PASS | 대표 결함 수정 대상 |
| 9 | 세로 JPEG | 화면비에 맞춰 중앙 cover crop | PASS | JPEG MIME 허용 |
| 10 | 가로 JPEG | 화면비에 맞춰 중앙 cover crop | PASS | JPEG MIME 허용 |
| 11 | 투명 PNG | 투명 영역 아래 기본 배경이 보임 | PASS | PNG MIME 허용 |
| 12 | `text/plain` 파일 | 거부 이유 표시 + 기존 이미지/편집 유지 | PASS | 지원하지 않는 파일은 decode 전 거부 |

## 대표 결함 수정 전후

긴 무공백 토큰 동일 입력 — **FAIL (수정 전)**: 단어 전체를 한 줄로 취급해 Canvas 사용 폭 밖으로 넘칠 수 있었다.

긴 무공백 토큰 동일 입력 — **PASS (수정 후)**: `measureText()`로 최대 폭을 확인하고, 단어 자체가 최대 폭보다 길면 Unicode 문자 단위로 다시 나눠 모든 줄이 사용 폭 안에 들어오도록 수정했다.

## 수동 확인 메모

- 이미지 9~11번은 브라우저에서 실제 PNG/JPEG 파일을 불러와 미리보기와 다운로드 파일을 나란히 확인한다.
- 12번은 `.txt` 파일을 넣고 오류 문구가 표시되는 동안 기존 문구·위치·이미지가 그대로인지 확인한다.
- 이 문서는 과제 증거용이며 최종 제출문에는 포함하지 않는다.
