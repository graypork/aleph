01

MONEY SAJU TEST

호기심을 서비스로 만들어봤습니다.

“나는 지금보다 미래에 돈을 더 많이 벌 수 있을까?” 재물에 대한 사주에서 출발한 질문을 실제로 사용할 수 있는 테스트 서비스로 만들었습니다.

PROJECT
Personal Web Service
ROLE
Planning / UI / Copy / Development
STATUS
Released
직접 테스트해보기 ↗

RESULT

무료로 사용할 수 있는 웹서비스를 직접 개발하고 실제 배포까지 완료했습니다.

START

재물에 대한 사주가 어느 정도 정해져 있다면, 현재보다 미래에 돈이 풍족할지, 더 많이 벌 수 있는 능력이 있는지, 어떤 방식으로 돈을 벌게 될지를 알려주는 테스트가 있으면 재미있겠다는 생각에서 시작했습니다.

DECISION

사용자가 결과를 편하게 읽을 수 있도록 UI의 가독성을 반복해서 수정했습니다. 결과 문구 역시 기계적으로 생성된 설명보다 사람이 직접 이야기하는 것처럼 느껴지도록 카피를 계속 다듬었습니다.

LEARNED

배포 이후 사주 콘텐츠에 관심이 높은 사용자와 금전이라는 주제에 강하게 반응하는 사용자가 내 예상처럼 일치하지 않을 수 있다는 기획의 모순을 발견했습니다. 기능을 더 추가하기보다 타깃과 초기 가설부터 다시 검토해야 한다고 판단해 추가 개발을 멈췄습니다.

02

BOOKAIVE

이전의 한계를 다음 기획의 기준으로 삼았습니다.

기억하고 싶어서 저장한 책의 문장들이 사진첩과 메모장에 흩어져 정작 다시 보이지 않는 문제에서 시작했습니다.

PROJECT
iOS Reading App
ROLE
Planning / Product / Development
STATUS
Building

RESULT

사진 저장과 OCR 텍스트 기록을 구현했고, 과거 기록을 다시 보여주는 ‘오늘의 책갈피’ 경험을 제작하고 있습니다.

IMGBOOKAIVE — 오늘의 책갈피 화면
IMGBOOKAIVE — OCR 저장 화면
IMGBOOKAIVE — 책갈피 탐색 화면

START

마음에 드는 문장은 사진으로 찍고 떠오른 생각은 메모장에 적었지만, 시간이 지나면 서로 다른 곳에 흩어져 결국 다시 보지 않게 됐습니다. 기억하려고 저장했지만 저장한 뒤부터 다시 잊고 있었습니다.

DECISION

이전 프로젝트에서 타깃을 충분히 구체화하지 않았다는 한계를 반영해 ‘꾸준히 책을 읽고 마음에 드는 문장을 기록하는 사람’으로 사용자를 먼저 좁혔습니다. 기능보다 ‘다 읽은 책을, 3초 안에.’라는 컨셉을 먼저 정하고 기능이 이 경험에 필요한지를 기준으로 판단하고 있습니다.

NEXT

MVP를 가능한 빠르게 완성한 뒤 실제 독서 사용자에게 사용하게 하고, 그 결과를 토대로 다음 방향을 결정할 계획입니다.

03

WRITING

생각을 머릿속에만 두지 않습니다.

생각은 많았지만 머릿속에만 두면 대부분 사라졌습니다. 인풋만큼 중요한 것이 아웃풋이라고 느꼈고, 가장 쉽게 시작할 수 있는 방법으로 글쓰기를 선택했습니다.

TYPE
Essay / Thoughts / Experience
PLATFORM
Blog / SNS
POSTS
약 20편
블로그 전체 보기 ↗

RESULT

약 20편의 글을 쌓았고 일부 글은 약 200회의 조회를 기록했습니다. 이전보다 글이 쉽게 읽힌다는 피드백도 받기 시작했습니다.

START

더 행복하게 살아가기 위해 부족하다고 느끼는 부분을 돌아보고, 책이나 경험을 통해 그것을 다르게 바라보게 된 생각들을 글로 기록하기 시작했습니다.

CHANGE

처음에는 제가 다시 읽기 위한 글에 가까웠지만, 계속 쓰면서 ‘내가 이해하는 글’과 ‘다른 사람이 이해할 수 있는 글’은 다르다는 것을 느꼈습니다. 지금은 처음 읽는 사람도 생각의 흐름을 따라올 수 있도록 구성과 문장을 수정하고 있습니다.
